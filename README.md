# DRIP: Drone Raw Image-to-Plot Georeferencing Workflow

**Version:** 1.0  
**Author:** Caiwang Zheng

## Overview

DRIP (**D**rone **R**aw **I**mage-to-**P**lot) is an open-source workflow for georeferencing individual UAV raw images without generating a full orthomosaic.

Instead of following the traditional workflow:

```text
Raw Images
    ↓
Orthomosaic
    ↓
Plot Extraction
```

DRIP directly performs:

```text
Raw Images
    ↓
Georeferencing
    ↓
Plot Extraction
```

This significantly reduces computational time while preserving the geometric relationship between the original images and field plots.

The workflow was developed for high-throughput plant phenotyping but can also be applied to other UAV remote sensing applications requiring plot-level image extraction.

## Workflow

The DRIP workflow consists of the following steps:

1. Load OpenSfM reconstruction
2. Read camera intrinsic parameters
3. Read camera extrinsic parameters
4. Estimate camera altitude above ground level (AGL) using nearby sparse point cloud points
5. Undistort image pixels
6. Project image rays into the world coordinate system
7. Intersect rays with the estimated ground plane
8. Convert local ENU coordinates into geographic coordinates
9. Transform geographic coordinates into the target UTM projection
10. Generate Ground Control Points (GCPs)
11. Create a georeferenced GeoTIFF for each raw image

---

## Methodology

Ground elevation is estimated from the local OpenSfM sparse point cloud using a KDTree nearest-neighbor search.

The camera center is computed as:

\[
C = -R^T T
\]

where:

- **R** = rotation matrix
- **T** = translation vector

Image rays are projected onto the estimated ground plane to determine the world coordinates of image pixels.

Unlike conventional approaches, DRIP does **not** require:

- Digital Elevation Models (DEMs)
- Orthomosaic generation

---

## Output

For every input image, DRIP generates:

```text
ImageName_georef.tif
```

Each GeoTIFF contains:

- Original RGB pixels
- UTM coordinate system
- Affine transformation estimated from generated GCPs

## Advantages

- Direct Raw Image-to-Plot workflow
- No orthomosaic generation required
- Fully open-source
- Computationally efficient
- Suitable for high-throughput phenotyping
- Compatible with OpenDroneMap/OpenSfM outputs
- Preserves original image quality
